# 写作规范

[← Wiki 首页](../README.md) > [附录](../README.md) > 写作规范

## 语言
- 中文为主；专有名词、类名、文件名、配置项、环境变量保留英文原词。
- 标点用全角中文，但代码块内保留 ASCII。

## 五段式（每个模块页固定次序的二级标题）
1. `## 是什么` — 一句话定义 + 关键源码锚点（`vllm/path/file.py:行号`）。
2. `## 为什么` — 必要性、动机、与替代方案比较。
3. `## 怎么做` — 实现原理、数据结构、调用流。优先用 mermaid 图示。
4. `## 与其它模块/系统配合` — 用相对路径链接到兄弟模块/子系统。
5. `## 历史版本演进` — 按 vLLM 版本号（v0.5 / v0.6 / v0.7 / v0.8 / v0.9 / v0.10 / v0.10.x / v0.11 / v0.12 / main）或日期；不确定写"早期/中期/近期"或 `(待核实)`。

## 导航约定
- 模块页顶部：`[← Wiki 首页](../README.md) > [子系统名](../README.md) > 当前模块名`；多级子目录按层级补足。
- 模块页底部：`[← 返回子系统首页](../README.md)` + `## 参见`（链接 2–6 个强相关模块）。
- 子系统 README 顶部：`[← Wiki 首页](../README.md)`，并含子目录导航表。
- 所有链接用相对路径，禁止绝对 URL。

## 源码引用
- 格式：`vllm/相对/路径/to/file.py:行号`；行号不确定时省略但仍给文件路径。
- 禁止杜撰类名/路径/行号；无法核实标 `(待核实)` 或 `(待补充)`。

## 图示
- 优先使用 mermaid（flowchart / sequenceDiagram / classDiagram）。
- 任何图示必须与文字描述互补，不替代源码引用。

## 版本标注
- 主要锚点：v0.5（2024 上半年）、v0.6（2024-09）、v0.7（2024-11，v1 落地）、v0.8（2025-02，v1 默认）、v0.8.x、v0.9（2025-04）、v0.9.x、v0.10（2025-06）、v0.10.x、v0.11（2025 Q3）、v0.12（2025 Q4）、main（持续）。
- 各模块页演进小节按需点出版本号 + 变更要点 + 触发动机 + 影响；无法对应版本号写"早期/中期/近期"。

## 不确定处理
- 显式标注 `(待核实)` / `(待补充)`，并在可能时给"为什么要核实"的原因。
- 已通过子 agent 批量产出；后续审校把每条 `(待核实)` 收敛为正式版本号或删除该论断。

## 维护
- 任何结构变更（新增/合并/改名子模块）需同步更新：本子系统 README 导航表 + 顶层 [`README.md`](../README.md) 导航树 + 强相关模块的 `## 参见`。
- 顶层导航树、子系统首页不允许过期。
